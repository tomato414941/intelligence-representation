# Cellular Rule Inference: Noise And Regime Changes

This bounded follow-up to [clean rule inference](cellular-rule-inference.md)
asks whether observed evidence can be combined when it is erroneous or stale.
It retains the 6x6 boards, eight-example cap and d256/h1024/heads8/l6 model.
It does not introduce persistent memory or a new architecture.

## Protocol Fixed Before Follow-up Results

1. Repeat the original 6000-step clean training with model seeds 32 and 33.
   Keep the rule pool, generated training episodes and original validation/test
   protocol fixed. Report each seed, not just the best checkpoint.
2. Evaluate frozen models with demonstration output cells independently flipped
   at rates 0, 0.05, 0.1 and 0.2. Inputs, queries and query targets remain clean.
   Use nested contexts of 0, 1, 4 and 8 examples with common corruption draws.
3. Keep eight chronological demonstrations, replacing the last 0/1/2/4/6/8
   old-rule outputs with new-rule outputs. Query targets always use the new rule.
   Repeat with 0/10/20% output noise. The model receives neither rule identities
   nor a change-point marker. Each initial board is sampled independently; this
   is chronological system identification, not a simulated board trajectory.

Zero observations after a change makes the change unobservable. Report that
condition for context, but do not call its error an adaptation failure.

Stress validation uses 32 disjoint rule pairs, four queries per pair,
rule/data seeds 29101/33001. Final stress evaluation uses 64 disjoint pairs,
eight queries per pair, seeds 39101/43001. Exclude all training rules and the
original clean validation/test identities from both, and stress-validation
identities from the final test. All models use the same evaluation pairs.

## Controls And Measurements

- Geometry-free conditional output frequency with Beta(1,1) smoothing.
- Family-aware Bayesian rule-bit inference, given the true sensor noise rate.
  Unknown bits have prior 1/2; B0 is fixed to zero. Its point prediction is
  local majority vote, with ties choosing zero. This privileged baseline knows
  the cellular family and noise rate, but receives no rule identity or boundary.
  Under changing rules its stationary assumption is deliberately misspecified.
  At zero noise, inconsistent histories use the limiting majority vote.
- The same family method with only the most recent two or four examples.
- The neural model using all eight examples, only the most recent two,
  reversed example order, and only examples after the true change point.
  That last control has privileged boundary information and measures the cost
  of stale history; it is not an implementable unknown-boundary detector.
- The same model with all eight examples generated by the current rule is the
  stable-environment reference. Noise-induced stable accuracy loss is measured;
  this is not a literal change-detector false-alarm rate.

Report accuracy, binary Brier score and negative log likelihood against clean
targets (NLL probabilities clipped to [1e-7, 1-1e-7]). For changes, separately
count cells where old/new targets differ, and the subset whose local condition
has appeared after the change. Accuracy confidence intervals resample whole
disjoint rule pairs. They do not measure training-seed variation.

## Bounded Follow-up Training

Use frozen seed 31 stress validation to decide whether augmentation is needed.
A loss of at least three accuracy points at 10% noise and eight examples calls
for a noise-trained model. An advantage of at least three points for the
current-only control over full history at four post-change observations and
10% noise calls for a model trained on changes. These are engineering triggers,
not significance tests or universal success thresholds.

If triggered, train each variant once from scratch for the same 6000 steps,
model seed 31 and standard architecture. The noise variant samples 0/5/10/20%
noise uniformly per episode. The change variant additionally uses an old-rule
prefix with probability 0.5 for contexts of at least two examples; both rules
come only from the training pool, differ by identity, and at least one current
example remains. Prefix lengths are uniform from one to context length minus
one. Targets remain the clean current-rule output. A separate augmentation RNG
keeps the base boards, current rules and context counts identical to clean
training. Resume checkpoints retain both RNG states.

These variants are exploratory single-seed results. Do not select checkpoints
or tune hyperparameters using the final stress test. The existing checkpoint
loader can evaluate original clean checkpoints; resuming training requires a
matching full training configuration.

## Reproduction

Use `python -m intrep.problems.cellular_rule_inference.stress --help` for the
evaluation CLI. Pass repeatable `--exclude-rules-from` arguments for the original
validation, original test, and (for final testing) stress validation JSON files.
The training CLI accepts `--observation-noise` and
`--rule-change-probability 0.5`. Default clean training is unchanged.

The runner `scripts/run_cellular_rule_stress_experiment.py` takes three
`--clean-checkpoint` arguments (seed 31 first), `--original-validation`,
`--original-test`, `--stress-validation`, and a new `--run-dir`. It writes the
validation-trigger decisions before training, trains enabled variants, then
evaluates all frozen checkpoints on final stress rules. Augmented variants also
receive the original clean final test. RunPod sync must include this script and
the supplied input artifacts, using the existing command runner.

## Validation Decisions

Measured 2026-09-10, frozen clean seed 31, 32 held-out pairs / 128 query boards.
At eight demonstrations accuracy was 98.50/97.35/94.90/86.87% for
0/5/10/20% output noise. The 10% loss was 3.60 points, exceeding the declared
three-point trigger for noise training. At 10% noise and four post-change
observations, full-history accuracy was 69.21%; the current-only control reached
92.84%. This 23.63-point stale-history penalty triggered change training.

No final stress-test result was used for those decisions. Both augmented
variants will use one 6000-step run from seed 31, without a hyperparameter sweep.
Final results and durable artifact hashes will be recorded after verification.
